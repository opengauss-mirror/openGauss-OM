# one_master_one_slave.sh 脚本使用指导文档

## 一、脚本概述

​	**one_master_one_slave.sh** 是面向 openGauss 数据库的**一键两节点主备集群自动化部署脚本**，仅支持单主单备（1Master+1Standby）架构部署。脚本依托 expect 实现跨节点免交互 SSH 通信，可自动完成服务器环境初始化、集群用户配置、防火墙与系统参数优化、集群XML配置生成、数据库预安装与正式安装、集群状态校验全流程，大幅简化 openGauss 双节点高可用集群部署流程。

​	脚本适配 openEuler、CentOS、RedHat、麒麟等主流服务器系统，支持 x86_64、aarch64（ARM）架构，可用于物理机、虚拟机、Docker 容器测试环境部署。

## 二、运行前准备

- 脚本强制校验运行用户身份，**必须使用 root 用户执行**，非 root 用户直接退出执行，保障系统级配置、跨节点远程操作、数据库安装权限充足。
- 脚本**仅支持两个节点部署**（一主一备），不支持单节点、三节点及以上集群架构，传入节点IP数量非2个将直接报错退出。
- 主备节点系统架构，操作系统以及版本，时钟服务必须保持一致。
- 主备节点root用户密码必须一致
- 主备节点手动创建安装用户，并设置安装用户密码，且密码必须与root用户一致
- 脚本**仅执行集群配置、预安装、安装、初始化流程**，不包含 openGauss 官方安装包的下载、传输、解压、基础环境预处理逻辑

- 下载openGauss企业版安装包，到安装目录，解压企业版安装包，解压ALL安装包后，继续解压OM安装包
-  备机同步执行4.1步骤操作，且保持目录一致
- 上传one_master_one_slave.sh脚本，以及模版xml文件 到主节点解压企业版安装包目录simpleInstall/one_master_one_slave.sh，确保备节点存在相同目录



## 三、脚本参数使用说明

脚本通过命令行传参执行部署，支持自定义集群用户、端口、安装路径、节点IP等核心参数，所有参数均为可选传参，部分参数存在默认值，缺失必填参数将终止执行。

| 参数 | 全称               | 作用说明                                     | 是否必填 | 默认值               |
| :--- | :----------------- | :------------------------------------------- | :------- | :------------------- |
| -h   | --help             | 输出脚本帮助信息与参数说明                   | 否       | -                    |
| -U   | --user_name        | 指定 openGauss 集群运行普通用户              | 是       | 无                   |
| -G   | --user_grp         | 指定集群用户所属用户组                       | 否       | dbgrp                |
| -H   | --host_ip          | 双节点内网IP，逗号分隔（主节点,备节点）      | 是       | 无                   |
| -p   | --port             | openGauss 数据库服务端口                     | 否       | 20050                |
| -D   | --install_location | 数据库程序安装根目录                         | 否       | 对应用户家目录       |
| -X   | --xml_location     | openGauss 集群部署XML模板文件路径            | 否       | 脚本同级目录模板文件 |
| -P   | --password         | root及集群用户密码，用于远程连接与用户初始化 | 否       | 交互式手动输入       |

## 四、核心执行流程

脚本执行遵循标准化闭环部署流程，全程自动化无需人工干预，具体步骤如下：

1. **权限校验**：校验当前用户为 root，非 root 直接退出；
2. **参数解析校验**：读取用户传入参数，校验必填参数非空，拆分双节点IP数组；
3. **环境信息采集**：自动识别服务器系统版本、硬件架构，适配对应部署逻辑；远程获取双节点主机名；
4. **跨节点环境初始化**：本机与远端节点批量创建用户组、集群用户，设置用户密码，关闭SELinux、放行数据库端口，初始化安装目录权限；
5. **集群配置生成**：基于XML模板，自动替换节点信息、端口、安装路径等参数，生成正式集群部署配置文件；
6. **数据库部署**：加载系统环境变量，执行 openGauss 预安装、正式安装流程；
7. **集群校验**：自动查询集群运行状态，完成一主一备集群部署。

## 五、特殊运行模式说明

脚本内置 **inner 内部模式**，无需人工调用，由脚本自动触发：主控节点通过SSH将脚本推送至备节点，以 inner 模式运行，仅执行节点环境初始化配置，不重复执行完整部署流程，实现双节点环境统一配置。

## 六、使用示例

标准两节点部署执行命令：

```bash
sh one_master_one_slave.sh -U gaussdb -G dbgrp -H 192.168.1.10,192.168.1.11 -p 20051 -D /usr2/wang_ogtest/install -P 'your_password'
```
